================================================================================
🎯 WHAT IS TARGETS MODULE?
================================================================================

The Targets & Projections module allows you to:
- Set sales targets for employees, branches, or company-wide
- Manage daily and monthly targets
- Track target periods with effective dates
- Filter and search targets by various criteria
- Maintain historical data (soft deletes)
- Generate reports for dashboards

================================================================================
📊 DATA STRUCTURE
================================================================================

TABLE: targets

Columns:
  • id              - Primary key
  • user_id         - Employee ID (optional)
  • branch_id       - Branch ID (optional)
  • target_type     - 'day' or 'month'
  • target_amount   - Amount in ₹ (decimal)
  • effective_from  - Start date
  • effective_to    - End date
  • description     - Notes/description
  • created_by      - Creator name
  • created_at      - Timestamp
  • updated_at      - Timestamp
  • deleted_at      - Soft delete timestamp

Sample Targets:
  1. Employee Monthly Target    → user_id=1001, branch_id=1, type=month
  2. Employee Daily Target      → user_id=1002, branch_id=2, type=day
  3. Branch-wide Target         → user_id=NULL, branch_id=1, type=month
  4. Company-wide Target        → user_id=NULL, branch_id=NULL, type=month

================================================================================
🔍 IMPORTANT FIELDS EXPLAINED
================================================================================

EMPLOYEE (user_id):
  - Which employee the target is for
  - Leave blank for branch/company-wide targets
  - Required: NO
  - From: User_Master.UserID

BRANCH (branch_id):
  - Which branch the target is for
  - Leave blank for company-wide targets
  - Required: NO
  - From: new_branches.id

TARGET TYPE:
  - 'day' = Daily sales target (usually for single day)
  - 'month' = Monthly sales target
  - Required: YES

TARGET AMOUNT:
  - The target value in Indian Rupees (₹)
  - Must be positive number
  - Format: 500000.00
  - Required: YES

EFFECTIVE FROM:
  - When the target starts
  - Format: YYYY-MM-DD
  - Required: YES

EFFECTIVE TO:
  - When the target ends
  - Format: YYYY-MM-DD
  - Must be >= Effective From
  - Required: YES

🎓 EXAMPLE QUERIES
================================================================================

Get employee's targets:
  $targets = Target::where('user_id', 1001)->get();

Get branch targets:
  $targets = Target::where('branch_id', 1)->get();

Get today's targets:
  $today = now()->toDateString();
  $targets = Target::where('effective_from', '<=', $today)
                   ->where('effective_to', '>=', $today)
                   ->get();

Get with relationships:
  $targets = Target::with(['employee', 'branch'])->get();

Daily targets only:
  $targets = Target::where('target_type', 'day')->get();

Monthly targets only:
  $targets = Target::where('target_type', 'month')->get();

Total target amount:
  $total = Target::sum('target_amount');
